# 📝 Online Aptitude Test System

## 📌 Project Overview

The **Online Aptitude Test System** is a web-based application developed as a Third Semester project in Advanced Java.
This system is designed to conduct aptitude tests online in an efficient and user-friendly way.

It provides two main panels:

* 👨‍🎓 **Student Panel** – for taking tests and registration
* 👨‍💼 **Admin Panel** – for managing questions, categories, and users

The project aims to reduce manual testing efforts and provide an automated examination environment.

---

## 🎯 Objectives

* To provide an online platform for aptitude testing
* To manage students and questions digitally
* To ensure fast, accurate, and fair assessment
* To improve efficiency over manual testing systems
